# Coffeeboom MEGA — Семестровый проект по Web Technologies

## О проекте
Данный проект представляет собой первую часть семестровой работы по курсу веб-технологий (Assignment 1). Это статический веб-сайт из 6 страниц, посвященный реально существующей кофейне Coffeeboom в ТРЦ MEGA. 

## Особенности реализации
* Проект написан на чистом HTML5 без использования CSS и JavaScript (в соответствии с требованиями первой недели).
* Полностью соблюдена семантическая структура (header, nav, main, footer, section, article).
* Реализованы таблицы, списки, HTML-формы с полным набором input-полей.
* Код проходит проверку W3C Validator без ошибок и предупреждений.
