Как создавался данный сайт

Разработка веб-ресурса для кофейни Coffeeboom проходила в несколько этапов с использованием чистого HTML5 без применения CSS-стилей и сторонних фреймворков.

Для сохранения истории изменений и совместной работы использовалась система контроля версий Git. Основные команды терминала: 

git status
git add .
git commit -m "Add colophon and about pages"
git push origin main

Чтобы проверить статус репозитория в консоли, используйте сочетание клавиш Ctrl + C для отмены текущего процесса и введите команду git status.

Пример успешного вывода системы после проверки файлов браузером:

W3C Validator: Document checking completed. No errors found.
