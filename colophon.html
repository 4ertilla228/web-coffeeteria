Технологии и инструменты

Этот сайт был разработан в рамках первого задания по курсу веб-технологий. Нашей главной задачей было создание чистого, семантически правильного HTML-кода без использования каскадных таблиц стилей (CSS) и клиентских скриптов (JavaScript). Мы работали в команде из двух человек, выбрав для проекта реально существующую кофейню Coffeeboom, расположенную в торговом центре MEGA в Астане.

В качестве основного редактора кода мы использовали Visual Studio Code, так как он предоставляет удобную подсветку синтаксиса и интеграцию с системой контроля версий Git. Для форматирования документов и сохранения изменений мы регулярно применяли горячие клавиши. Например, чтобы сохранить файл, я скачал расширение, который автоматически сохраняет, а для быстрого поиска по коду использовали Ctrl + F.

Структура навигации

При разработке мы активно применяли семантические теги HTML5. Например, на каждой странице внедрен тег <nav>, внутри которого находится маркированный список ссылок. Вот фрагмент нашего кода:

<nav>
    <ul>
        <li><a href="index.html">Главная</a></li>
        <li><a href="menu.html">Меню</a></li>
    </ul>
</nav>

Особое внимание мы уделяли проверке качества. Мы прогоняли каждую страницу через официальный W3C Validator. Если валидатор находил проблему (например, пробел в имени картинки), он выдавал системное сообщение, похожее на это:

Error: Bad value images/foto 1.png for attribute src on element img: Illegal character in path segment.

Мы оперативно исправляли подобные недочеты, чтобы добиться нулевого количества ошибок и полного соответствия стандартам.
